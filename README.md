## About the Game
Sands of Eternity is a 2D top-down adventure game in which the player explores a forgotten Egyptian pyramid, collects Sun Gems, avoids dangerous traps, unlocks the Golden Door, collects the Heart of Eternity and escapes.

## Gameplay Features
- 8 playable levels
- WASD and Arrow Key movement
- Sun Gem collection system
- Score and Lives system
- Boulder and Spike traps
- Golden Door unlocking
- Heart of Eternity collectible
- 30-second escape timer
- Victory and Game Over screens
- Background music and sound effects
- Player name and best score saving

## Controls
| Key | Action |
|---|---|
| W / Up Arrow | Move Up |
| A / Left Arrow | Move Left |
| S / Down Arrow | Move Down |
| D / Right Arrow | Move Right |
| ESC | Pause / Resume |
| R | Restart |
| ENTER | Start / Next Level |
| Q | Quit |

## Project Structure
- Assets – Game resources and scripts
- Packages – Unity package dependencies
- ProjectSettings – Unity project configuration

## How to Run
1. Download or clone this repository.
2. Open the project using Unity 2022.3.62f3.
3. Open the Main scene.
4. Press Play to run the game.

For standalone Windows gameplay, use the separately supplied Windows Build folder.
